=====
Usage
=====

Wizard
======

The wizard is accessible from the TYPO3 backend module "Landing Page" in the
Web module group.

Step 1: Template Selection
--------------------------

Choose from the available landing page templates. Each template card shows its
title and description. Templates are filtered by backend user group access.

Step 2: Briefing
----------------

If the selected template has briefing mode set to ``required`` or ``optional``,
the wizard presents LLM-generated questions. Answering these questions helps the
LLM produce more targeted content.

When briefing mode is ``none``, this step is skipped entirely.

Step 3: Page Fields
-------------------

The LLM generates page-level fields such as the page title, SEO description,
and Open Graph metadata. All fields can be reviewed and edited before proceeding.

Step 4: Content Preview
-----------------------

Generated content sections are displayed for review. Each section includes a
header, subheader, and body text mapped to a TYPO3 content element type.

Individual sections can be regenerated without affecting the rest.

Step 5: Placement & Save
-------------------------

Set the page title, URL slug, and parent page. Click save to create the landing
page with all its content elements in the TYPO3 page tree.

Context Menu
============

Right-click any page in the page tree to find the "Create Landing Page" option.
This opens the wizard with the clicked page pre-selected as the parent page.

PSR-14 Events
=============

BeforePageCreationEvent
-----------------------

Dispatched before the page record is written to the database. Use this to modify
page properties, add custom fields, or enforce business rules.

AfterContentGenerationEvent
---------------------------

Dispatched after content sections have been generated by the LLM but before they
are saved as content elements. Use this to filter, transform, or enrich sections.
