=============
Configuration
=============

Templates
=========

Templates are the central configuration element. They are managed as TCA records
in the TYPO3 backend (table ``tx_nrlandingpage_domain_model_template``).

Each template defines:

Title / Identifier
   A human-readable title and a unique machine identifier.

System Prompt
   The LLM prompt that controls content generation style and structure.

Allowed CTypes
   Which content element types (e.g. ``text``, ``textmedia``, ``header``) the
   template may produce.

Page Fields
   Which page-level fields are generated by the LLM (e.g. ``description``,
   ``og:title``, ``og:description``).

Reference Pages
   Existing TYPO3 pages whose structure and content serve as a reference for
   the LLM when generating new content.

Briefing Mode
   Controls whether the briefing step is ``required``, ``optional``, or ``none``
   (skipped entirely).

Publish Mode
   Whether newly created pages are created as ``hidden`` (default) or ``visible``.

Backend User Groups
   Restricts which backend user groups can see and use this template.

LLM Configuration
==================

The extension uses ``netresearch/nr-llm`` for all LLM communication. Configure
your LLM backend (API keys, model selection, endpoint URLs) according to the
nr-llm extension documentation.

Each template can optionally reference a specific LLM configuration record,
allowing different templates to use different models or providers.
